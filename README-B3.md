## B3: *User Stories*

A [*User Story*](https://en.wikipedia.org/wiki/User_story) is an informal,
natural language formulation of a feature or function of a software system.

*User Stories* follow a simple *subject-predicate-object* structure that
captures:

- an *ID* of the story,

- a *role* as subject *"who"* (an actor) wants to achieve something,

- followed by an *action* (a verb) that describes *"what"* needs to be done.

- Often, a reason is added *"why"* the story is important.

The sentence structure is:

```
<ID>: As a <role>, I want <action>.

<ID>: As a <role>, I want <action>, so that <goal>.

Acceptance criteria (AC):
<ID>: When <condition>, then <effect>.
```

*Epics* can be used to group and organize larger numbers of user stories.
