## B2: *UML - Use Case Diagram*

[*Use Cases*](https://en.wikipedia.org/wiki/Use_case) describe what a user
expects of a software system or an application and how he/she
would interact with that system.

The [*UML - Use Case Diagram*](https://en.wikipedia.org/wiki/Use_case_diagram)
is a simple visual technique to illustrate and discuss *Use Cases*.

Tutorial
[*"UML - Use Case Diagrams: Everything you need to know"*](https://www.youtube.com/watch?v=4emxjxonNRI)
provides a good introduction (12:41min).


&nbsp;
